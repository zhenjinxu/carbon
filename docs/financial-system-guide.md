## 系统概述

Carbon ERP 财务系统为装备制造企业提供完整的财务管理解决方案，包括：

- **总账管理**：会计科目、凭证、日记账
- **应收应付**：客户和供应商管理
- **库存核算**：与库存模块无缝集成
- **成本管理**：直接材料、直接人工、制造费用
- **固定资产**：资产采购、折旧、处置
- **财务报表**：资产负债表、利润表、试算平衡表

### 核心特性

1. **实时过账**：业务操作自动触发财务凭证
2. **多币种支持**：外币业务自动汇率换算
3. **多维度核算**：成本中心、部门、项目
4. **审计追踪**：完整的操作日志和凭证追溯

## 会计科目体系

### 科目编码规则

采用 4 位数编码体系，按科目类别分段：

| 编码范围 | 科目类别 | 说明 |
|---------|---------|------|
| 1000-1999 | 资产类 | 流动资产、固定资产、无形资产 |
| 2000-2999 | 负债类 | 流动负债、长期负债、应交税费 |
| 3000-3999 | 所有者权益类 | 实收资本、资本公积、未分配利润 |
| 4000-4999 | 收入类 | 主营业务收入、其他业务收入 |
| 5000-5999 | 成本类 | 主营业务成本、制造费用 |
| 6000-6999 | 费用类 | 销售费用、管理费用、财务费用 |

## 与其他模块的集成

### 1. 库存模块集成

#### 采购入库

**业务流程**：
```
采购订单 → 收货 → 过账 → 财务凭证
```

**自动生成的凭证**：
```
借：原材料/库存商品    1200/1220
    贷：应付账款        2100
```

**配置说明**：
- 在"默认账户"页面配置：
  - `库存账户`：原材料/库存商品科目
  - `应付账款`：应付账款科目
  - `GR/IR清算`： goodsReceivedNotInvoicedAccount

#### 销售出库

**业务流程**：

销售订单 → 发货 → 过账 → 财务凭证
```

```

**配置说明**：
- 在"默认账户"页面配置：
  - `主营业务成本`：主营业务成本科目

## 日常操作流程

### 1. 会计期间管理

**路径**：`财务` > `会计期间`

**操作步骤**：
1. 创建会计年度
2. 创建月度会计期间
3. 激活当前期间
4. 关闭已完成期间

**注意事项**：
- 每月只能有一个激活的会计期间
- 已关闭的期间不能录入凭证
- 年末需要进行年结处理

### 2. 凭证录入

**路径**：`财务` > `日记账` > `新建`

**操作步骤**：
1. 选择凭证类型（手工凭证/自动凭证）
2. 录入凭证日期
3. 录入摘要
4. 录入科目和金额
5. 保存并过账

**凭证类型**：
- **手工凭证**：手动录入的凭证
- **自动凭证**：由业务操作自动生成的凭证
- **调整凭证**：用于期末调整的凭证

### 3. 科目余额查询

**路径**：`财务` > `试算平衡表`

**功能**：
- 查询科目余额
- 查询科目发生额
- 导出科目余额表

### 4. 凭证查询

**路径**：`财务` > `日记账` > `查询`

**功能**：
- 按日期查询凭证
- 按科目查询凭证
- 按摘要查询凭证
- 导出凭证

## 月末结账流程

### 1. 月末检查清单

**路径**：`财务` > `月末结账`

**检查项目**：
- [ ] 所有业务凭证已过账
- [ ] 库存盘点差异已处理
- [ ] 固定资产折旧已计提
- [ ] 汇兑损益已调整
- [ ] 费用分摊已完成

### 2. 自动结转

**路径**：`财务` > `月末结账` > `自动结转`

**结转项目**：
- 收入类科目结转至本年利润
- 费用类科目结转至本年利润
- 成本类科目结转至本年利润

### 3. 试算平衡

**路径**：`财务` > `试算平衡表`

**检查项目**：
- 资产 = 负债 + 所有者权益
- 借方合计 = 贷方合计

### 4. 关闭会计期间

**路径**：`财务` > `会计期间` > `关闭`

**操作步骤**：
1. 确认所有凭证已过账
2. 确认试算平衡
3. 关闭当前期间
4. 开启下一期间

## 常见问题

### Q1: 为什么过账时提示"Error getting account defaults"？

**A**: 这是因为系统需要默认会计科目来生成凭证。请在"财务" > "配置" > "默认账户"页面配置必要的默认科目。

### Q2: 如何查看自动生成的凭证？

**A**: 在"财务" > "日记账" > "查询"中，可以通过业务单据号查询对应的凭证。

### Q3: 如何修改已生成的凭证？

**A**: 已生成的凭证不能直接修改。如果需要修改，请先冲销原凭证，然后重新生成。

### Q4: 如何处理跨期业务？

**A**: 对于跨期业务，可以使用"预提"或"待摊"科目进行处理，确保业务归属正确的会计期间。

### Q5: 如何进行年结处理？

**A**: 年结处理包括：
1. 完成12月份的月末结账
2. 生成年度财务报表
3. 进行年结结转
4. 创建新的会计年度
